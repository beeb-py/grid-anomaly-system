# Grid Anomaly Detection System

End-to-end machine learning system for detecting anomalies in power grid time series data using ENTSO-E data.

## Features
- Data ingestion from ENTSO-E API
- Feature engineering for time series
- Anomaly detection (Isolation Forest, LSTM Autoencoder)
- FastAPI backend
- Gradio interactive UI
